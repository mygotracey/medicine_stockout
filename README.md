# medicine_stockout
## Data Source

Zdravković, M. (2020). *Pharma Sales Data* [Data set]. Kaggle.
https://www.kaggle.com/datasets/milanzdravkovic/pharma-sales-data

The dataset contains six years (2014–2019) of pharmacy sales, grouped into 8 ATC drug categories.
All credit for the data goes to the original author. The raw file is not modified in this project.
